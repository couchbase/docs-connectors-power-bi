== Introduction

You can build data visualization dashboards that provide live overviews of the data stored in your on-premise Couchbase data sources. 

This guide will walk you through the process of installing and configuring the Power BI Cloud Gateway to enable secure data integration between Power BI and your on-premises Couchbase data sources.

== Prerequisites
Before using the Power BI Cloud Gateway, you must first install and set up.

* xref:index.adoc#install-power-bi-desktop[The Power BI Desktop application].
* xref:index.adoc#install-ODBC-driver[The Couchbase ODBC driver].
* xref:index.adoc#install-Power-BI-connector[The Couchbase Custom Connector].

Instructions for installing the prerequisites can be found on the  xref:index.adoc[] page.

https://powerbi.microsoft.com/en-in/gateway[PowerBI Gateway download].

== Access Power BI 

You can access the cloud version of Power BI at https://app.powerbi.com[]. Sign in to your account or create a new one if required.

== Link Your Power BI Cloud to Your Power BI Desktop

. Select menu:Settings[Manage Connections and Gateways]
+
image::power-bi-cloud-settings.png[,50%]

. Click on the btn:[{plus}New] button to create a new connection.

. Fill the details for the connection you created




== Publish a Report

First, you create a report using the Power BI desktop application and then publish to the cloud using the Power BI Cloud Gateway.

. Create and save a report using the PowerBI desktop.
. Select the btn:[Home] tab on the Power BI desktop.
. Click on the btn:[Publish] button.
. Enter your sign-in details as required.
. Select a workspace for publishing your report.

== Access Your Report

Refresh your https://app.powerbi.com[Power BI Cloud] page to see your published workspace.

NOTE: If you cannot see your published workspace, then sign out of Power BI Cloud and sign back in.

You can make sure that the gateway is loaded by accessing the menu:Settings[] page.

.Power BI workspace
image::power-bi-workspace.png[,70%]

From there, choose menu:Manage connections and gateways[], then select the menu:On-premises data gateways[] tab.
This shows you the live gateway connection you created.
