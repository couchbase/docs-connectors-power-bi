The xref:index.adoc[Couchbase Power BI Connector] lets you connect Microsoft Power BI to your Couchbase data sources for interactive data visualization.

[#v-2-0]
== Version 2.0 (2026-10-19)

* The Power BI connector now uses the new names for the Couchbase Analytics products:
+
--
** Enterprise Analytics is now Operational Insights Enterprise.
** Capella Analytics is now Operational Insights Capella.
--
+
When you configure an ODBC Data Source Name (DSN), select the data source by its new name.

* The ODBC driver now trusts certificates in the Windows certificate store.
You need to specify *Cluster Cert Path* only if Windows does not trust your cluster certificate.
For more information, see xref:index.adoc#certificate-and-hostname-verification[Certificate and Hostname Verification].

* The ODBC driver now verifies that the cluster certificate matches the hostname or IP address that the driver connects to.
Hostname verification is on by default.
If an existing connection fails with a hostname mismatch after you upgrade, use a certificate that includes the hostname, or set `verify_hostname=false` in *Advanced Parameters*.
For more information, see xref:index.adoc#certificate-and-hostname-verification[Certificate and Hostname Verification].
